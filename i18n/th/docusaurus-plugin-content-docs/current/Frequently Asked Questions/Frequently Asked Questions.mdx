# คำถามที่พบบ่อย (FAQs)

รวบรวมคำถามและคำตอบที่พบบ่อยเกี่ยวกับ **GemLogin Anti-detect Browser & Automation Platform**

---

## Browser Profile

<Details summary="Browser Profile คืออะไร?">

Browser Profile คือสภาพแวดล้อมเบราว์เซอร์ที่แยกเป็นเอกเทศ (Sandbox) โดยแต่ละโปรไฟล์จะมีลายนิ้วมือเบราว์เซอร์ (Fingerprint), คุกกี้ (Cookies), หน่วยเก็บข้อมูลในเครื่อง (Local Storage) และการตั้งค่าเครือข่ายของตัวเอง ซึ่งจะทำให้แต่ละโปรไฟล์ดูเหมือนมาจากคนละอุปกรณ์ ป้องกันการเชื่อมโยงข้ามบัญชี

</Details>

<Details summary="วิธีการสร้างโปรไฟล์ทำอย่างไร?">

วิธีการสร้างโปรไฟล์มี 4 รูปแบบหลัก:

| รูปแบบการสร้าง | เหมาะสำหรับ |
|------|----------|
| [Single Create](/docs/tutorial-basics/Profile/Create%20Profile#single-create) | สร้างทีละโปรไฟล์ พร้อมระบุการตั้งค่าอย่างละเอียด |
| [Multiple Create](/docs/tutorial-basics/Profile/Create%20Profile#multiple-create) | สร้างโปรไฟล์หลายตัวพร้อมกันอย่างรวดเร็ว |
| [Import File](/docs/tutorial-basics/Profile/Create%20Profile#import-file) | นำเข้าโปรไฟล์จำนวนมากผ่านไฟล์ Excel (.xlsx / .csv) |
| [Import from External](/docs/tutorial-basics/Profile/Create%20Profile#import-from-external) | ตรวจสอบและนำเข้าโปรไฟล์ที่มีอยู่แล้วจาก Chrome |

</Details>

<Details summary="ทำไมลายนิ้วมือเบราว์เซอร์ (Fingerprint) ต้องสอดคล้องกัน?">

ข้อมูลลายนิ้วมือเบราว์เซอร์ต้องมีความสอดคล้องกับเครือข่ายเพื่อความปลอดภัยสูงสุด:

```
✅ IP ตรงกับประเทศ
✅ ประเทศตรงกับเขตเวลา (Timezone)
✅ ภาษาตรงกับภูมิภาคของ IP
✅ เวอร์ชันเบราว์เซอร์สมจริง
✅ พิกัดทางภูมิศาสตร์ (Geolocation) ตรงกับ IP
```

ตัวอย่าง **ความเสี่ยงสูงที่จะถูกตรวจจับ**:

```
❌ IP เวียดนาม + เขตเวลาสหรัฐฯ + ภาษาลัตเวีย + ระบบปฏิบัติการ Windows แต่ใช้ MacOS User-Agent
```

</Details>

<Details summary="การตั้งค่าพร็อกซี (Proxy) ทำอย่างไร?">

SOCKS5 (แนะนำ):

```
1. เปิดเมนู Create Profile หรือแก้ไขโปรไฟล์
2. เลือก Proxy Type เป็น SOCKS5
3. กรอกในรูปแบบ host:port:username:password
4. กด Check เพื่อทดสอบการเชื่อมต่อ
```

</Details>

## Workflows & Automation

<Details summary="จะสร้างสคริปต์อัตโนมัติได้อย่างไร?">

1. ไปที่เมนู **Workflows**
2. คลิก **+ Create Workflow**
3. ลากบล็อกคำสั่งจากพาเนลซ้ายมือวางลงบนผังงาน (Canvas)
4. เชื่อมต่อเส้นโหนดระหว่างบล็อกคำสั่ง
5. กำหนดค่าในพาเนลขวามือ
6. กดปุ่มบันทึก หรือทดสอบสั่งรัน

</Details>

<Details summary="สามารถแชร์สคริปต์ให้ผู้อื่นได้หรือไม่?">

ได้ 2 วิธี:

* **Export Script**: ส่งออกสคริปต์เป็นไฟล์ `.json` แล้วส่งให้เพื่อนนำเข้า
* **Template Marketplace**: เผยแพร่สคริปต์ลงในคลังสำเร็จรูป

</Details>
