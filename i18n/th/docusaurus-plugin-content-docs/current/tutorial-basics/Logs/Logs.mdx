# บันทึกประวัติการทำงาน (Logs)

หน้า **Logs** ใช้สำหรับตรวจสอบประวัติการรันสคริปต์อัตโนมัติ ติดตามสถานะความสำเร็จ รายงานข้อผิดพลาด และสถิติการรันงานย้อนหลัง

---

## ฟีเจอร์หลักในหน้า Logs

| ฟีเจอร์ | คำอธิบาย |
| :--- | :--- |
| **Search & Filter** | ค้นหาประวัติตามชื่อสคริปต์ ชื่อโปรไฟล์ หรือกรองตามสถานะ (`Success` / `Error`) |
| **Log Details** | คลิกดูบันทึกคำสั่งและเวลาประมวลผลอย่างละเอียดในแต่ละขั้นตอน |
| **Export Log** | ส่งออกไฟล์ประวัติการทำงานสำหรับนำไปวิเคราะห์ผลต่อ |
| **Clear Log** | ล้างประวัติเก่าเพื่อคืนพื้นที่จัดเก็บในระบบ |
