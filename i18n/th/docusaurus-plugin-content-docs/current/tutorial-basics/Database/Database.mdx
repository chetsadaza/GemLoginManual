# การจัดการฐานข้อมูล (Database Management)

ระบบ **Database** ของ GemLogin ช่วยจัดการและกักเก็บข้อมูลส่วนกลางสำหรับสคริปต์ Automation ประกอบด้วย 3 ส่วนสำคัญ: **Data Tables** (ตารางข้อมูล), **Variables** (ตัวแปรสคริปต์) และ **Credentials** (ข้อมูลล็อกอินปลอดภัยสูง)

---

## 1. Data Tables (ตารางข้อมูลหลัก)

ใช้สำหรับจัดเก็บและป้อนข้อมูลเข้าสคริปต์ (เช่น รายชื่อบัญชี, ข้อความคอมเมนต์, ลิงก์สินค้า)

* **+ Create table**: สร้างตารางข้อมูลใหม่
* **การจัดการคอลัมน์ (Data Types)**:
  * `Text`: ข้อความทั่วไป
  * `Number`: ตัวเลข
  * `Boolean`: ค่าความจริง (`true` / `false`)
  * `JSON`: ข้อมูลโครงสร้าง JSON
* **Import / Export**: รองรับการนำเข้าและส่งออกข้อมูลผ่านไฟล์ Excel หรือ CSV

---

## 2. Variables (ตัวแปรสคริปต์)

จัดเก็บค่าตัวแปรระดับระบบที่นำไปใช้ซ้ำในกระบวนการทำงานอัตโนมัติ (เช่น Token, API Key หรือข้อความคงที่)

| ฟิลด์ | คำอธิบาย |
| :--- | :--- |
| **Name** | ชื่อตัวแปรอ้างอิง (เช่น `GemLogin_API`) |
| **Value** | ค่าของตัวแปร (รองรับข้อความหลายบรรทัด) |

---

## 3. Credentials (ข้อมูลประจำตัวปลอดภัยสูง)

ส่วนจัดเก็บข้อมูลลับ เช่น รหัสผ่าน หรือ Private Key อย่างปลอดภัยเมื่อรันคำสั่งเบราว์เซอร์

* **+ Add credential**: เพิ่มข้อมูลล็อกอินใหม่
* ข้อมูลจะถูกเข้ารหัสความปลอดภัยเพื่อป้องกันการรั่วไหลขณะรันงานในทีม
