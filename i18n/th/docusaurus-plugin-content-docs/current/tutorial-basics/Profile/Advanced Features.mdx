# ฟีเจอร์และการปรับแต่งขั้นสูง (Advanced Features)

ฟีเจอร์ขั้นสูงในส่วนการสร้างและแก้ไขโปรไฟล์ ใช้สำหรับการกำหนดค่าลายนิ้วมือฮาร์ดแวร์ (Hardware Fingerprint) เชิงลึก ป้องกันการตรวจจับจากอัลกอริทึมวิเคราะห์เบราว์เซอร์ขั้นสูง

---

## หัวข้อการปรับแต่ง Fingerprint

| หัวข้อ | คำอธิบายและการใช้งาน |
| :--- | :--- |
| **Canvas** | กำหนดค่า Random Noise ให้กับการวาดภาพกราฟิก Canvas |
| **WebGL** | ปรับแต่งข้อมูลชิปกราฟิก (WebGL Vendor & Renderer) ให้ดูสมจริง |
| **Audio Context** | แทรก Noise สุ่มในค่าวิเคราะห์คลื่นเสียง Web Audio |
| **Fonts** | กำหนดรายการฟอนต์ระบบที่ติดตั้งอยู่ในเครื่องจำลอง |
| **Hardware Concurrency** | กำหนดจำนวนคอร์ประมวลผล CPU (เช่น `4`, `8`, `16`) |
| **Device Memory** | กำหนดขนาดหน่วยความจำแรมของเครื่อง (เช่น `4GB`, `8GB`) |
