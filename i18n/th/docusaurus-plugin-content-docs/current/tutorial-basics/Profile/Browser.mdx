# เมนูและการจัดการ Browser (Browser Actions)

เมนู **Browser Actions** รวบรวมฟีเจอร์สำหรับปรับแต่งโปรไฟล์แบบกลุ่ม เช่น การเปลี่ยนชื่อพร้อมกัน, ล้างคุกกี้/แคช, ปรับเปลี่ยนลายนิ้วมือฮาร์ดแวร์ (Fingerprint PRO), เปลี่ยนระบบปฏิบัติการ (OS) และตั้งค่าบุ๊กมาร์ก

---

## เมนูลัด Browser (Browser Menu)

เมื่อคลิกขวาที่โปรไฟล์และเลือกเมนู **Browser** จะปรากฏตัวเลือกดังต่อไปนี้:

| ตัวเลือก | คำอธิบาย |
| :--- | :--- |
| **Rename** | เปลี่ยนชื่อโปรไฟล์แบบกลุ่มอัตโนมัติหรือพิมพ์เปลี่ยนด้วยตนเอง |
| **Clear cookie** | ลบข้อมูลคุกกี้เซสชันเพื่อออกจากระบบทุกเว็บไซต์ |
| **Clear cache** | ลบไฟล์อินเทอร์เน็ตชั่วคราวเพื่อคืนพื้นที่และรีโหลดหน้าเว็บใหม่ |
| **Set chrome version** | ปรับเปลี่ยนเวอร์ชันของ Chrome Engine |
| **New fingerprint** | สุ่มสร้างลายนิ้วมือฮาร์ดแวร์ใหม่ (ฟีเจอร์ PRO) |
| **Change OS** | เปลี่ยนจำลองระบบปฏิบัติการ (Windows, MacOS, Linux, Android, iOS) |
| **Change location** | กำหนดพิกัดทางภูมิศาสตร์ (Latitude/Longitude) |
| **Bookmark** | เพิ่มและจัดการบุ๊กมาร์กเริ่มต้นในเบราว์เซอร์ |
| **Change name color** | เปลี่ยนสีและสไตล์ฟอนต์ชื่อโปรไฟล์ในรายการ |
| **Update start URL** | อัปเดตหน้าเว็บที่ต้องการให้เปิดอัตโนมัติ |

---

## 1. Rename (เปลี่ยนชื่อโปรไฟล์แบบกลุ่ม)

* **Auto Mode**: ตั้งรูปแบบชื่ออัตโนมัติด้วยตัวแปร เช่น `{current name}`, `{number from 1}`, `{today}` (ตัวอย่าง: `FB_Core_{number from 1}`)
* **Manual Mode**: พิมพ์หรือวางรายการชื่อใหม่บรรทัดละชื่อ

---

## 2. Cookie & Cache Management (การลบแคชและคุกกี้)

* **Clear cookie**: ลบข้อมูลเซสชันล็อกอิน เหมาะเมื่อต้องการเปลี่ยนบัญชีใช้งาน
* **Clear cache**: ลบไฟล์ค้างในเบราว์เซอร์ โดยไม่กระทบกับเซสชันการล็อกอิน

---

## 3. Fingerprint & OS Customization (ปรับแต่งลายนิ้วมือและระบบปฏิบัติการ)

* **New fingerprint (PRO)**: สุ่มสร้างค่า Canvas, WebGL, Audio Context และ Screen Resolution ใหม่เมื่อโปรไฟล์ถูกจับตามอง
* **Change OS**: เลือกระบบปฏิบัติการที่ต้องการจำลอง (Windows 11/10/7, MacOS, Linux, Android, iOS)
* **Change location**: เลือกประเทศและพิกัดตำแหน่งทางภูมิศาสตร์ให้ตรงกับ Proxy IP

---

## 4. Personalization (การจัดการบุ๊กมาร์กและสีชื่อ)

* **Bookmark**: นำเข้าบุ๊กมาร์กจากไฟล์ ZIP หรือพิมพ์รายการ `ชื่อ|URL` (เช่น `Google|https://google.com`)
* **Change name color**: กำหนดสี ความโปร่งแสง และสไตล์ฟอนต์ตัวเอียง/ขีดเส้นใต้ให้กับชื่อโปรไฟล์
