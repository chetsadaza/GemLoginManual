# เมนูและการจัดการ Actions (Profile Actions)

เมนู **Profile Actions** รวบรวมคำสั่งย่อยสำหรับจัดการ จัดหมวดหมู่ สำรองข้อมูล และซิงก์ข้อมูล Browser Profile เพื่อให้การย้ายเครื่องหรือแชร์โปรไฟล์ในทีมเป็นไปอย่างปลอดภัยและราบรื่น

---

## เมนูลัด Actions (Actions Menu)

เมื่อคลิกขวาที่โปรไฟล์และเลือกเมนู **Actions** จะปรากฏตัวเลือกการทำงานดังต่อไปนี้:

| ตัวเลือก | คำอธิบาย |
| :--- | :--- |
| **Assign group** | ย้ายโปรไฟล์ที่เลือกไปยังกลุ่มหรือหมวดหมู่ใหม่ |
| **Backup** | ส่งออกโปรไฟล์เป็นไฟล์บีบอัด ZIP หรือนำเข้าไฟล์สำรองข้อมูล |
| **Export cookies** | ดึงคุกกี้ออกจากโปรไฟล์ บันทึกเป็นไฟล์ JSON หรือ String |
| **Recover** | กู้คืนโปรไฟล์ย้อนกลับไปยังย้อนหลังหรือย้ายค่ายจากโปรแกรมอื่น |
| **Synchronize cloud** | ซิงก์คุกกี้และประวัติเบราว์เซอร์ในเครื่องขึ้นไปยัง Cloud |
| **Swap Profile** | สลับตำแหน่งหรือสลับโฟลเดอร์ข้อมูลระหว่างโปรไฟล์ |

---

## 1. Assign Group (ย้ายกลุ่มโปรไฟล์)

ใช้สำหรับจัดระเบียบโปรไฟล์ โดยย้ายโปรไฟล์ที่เลือกไปยังกลุ่มที่ต้องการ

* **Dropdown เลือกกลุ่ม**: เลือกกลุ่มที่มีอยู่เดิมในระบบ
* **ปุ่มเพิ่มกลุ่ม (+)**: คลิกที่ปุ่ม **+** เพื่อสร้างกลุ่มใหม่ทันทีโดยไม่ต้องปิดหน้าต่าง

---

## 2. Backup (สำรองและนำเข้าข้อมูล)

ระบบสำรองข้อมูลโปรไฟล์ช่วยป้องกันข้อมูลสูญหาย

### ส่งออกสำรองข้อมูล (Export Backup)
* **File Path**: เลือกโฟลเดอร์ปลายทางสำหรับบันทึกไฟล์ `.zip`
* **Clean export (skip cache, faster)**: ติ๊กเลือกเพื่อข้ามไฟล์แคชชั่วคราว ช่วยลดขนาดไฟล์และทำให้ส่งออกได้เร็วขึ้นมาก

### นำเข้าสำรองข้อมูล (Import Backup)
* **Select the ZIP file**: ลากไฟล์ `.zip` มาวางในกล่อง หรือคลิกปุ่มเพื่อเลือกไฟล์จากคอมพิวเตอร์

---

## 3. Export Cookies (ส่งออกคุกกี้)

สกัดคุกกี้เซสชันที่เข้าพักไว้ออกจากโปรไฟล์

> [!IMPORTANT]
> ฟังก์ชันนี้จะทำงานต่อเมื่อโปรไฟล์นั้นเปิดใช้งานตัวเลือก **Save cookie** ไว้เท่านั้น

* **Cookie Scope**: เลือก **All** (ส่งออกทุกเว็บไซต์) หรือ **Domain** (ระบุเฉพาะโดเมน เช่น `facebook.com`)
* **Format**: เลือกแบบ **JSON** (สำหรับบอตหรือ API) หรือ **String** (รูปแบบ Netscape สำหรับส่วนขยายเบราว์เซอร์)

---

## 4. Recover (กู้คืนและย้ายค่ายโปรไฟล์)

กู้คืนข้อมูลโปรไฟล์เดิม หรือย้ายข้อมูลจากโปรแกรม Anti-detect เบราว์เซอร์ค่ายอื่น (เช่น GPM, Genlogin)

* **Clean profiles before recovery**: เปิดสวิตช์นี้หากต้องการล้างข้อมูลเก่าก่อนกู้คืน ป้องกันปัญหาแคชตกค้าง
* **Core Engines / Format**: เลือกประเภทไฟล์ที่ต้องการกู้คืน (GemLogin Core, GPM, Genlogin, Other)

---

## 5. Synchronize Cloud & Swap Profile

* **Synchronize cloud**: สั่งอัปโหลดข้อมูลเซสชัน คุกกี้ และบุ๊กมาร์กล่าสุดขึ้น Cloud เพื่อให้ทีมงานรันต่อได้ทันที
* **Swap Profile**: สลับการตั้งค่าหรือโฟลเดอร์ข้อมูลระหว่างคู่โปรไฟล์ที่เลือกอย่างรวดเร็ว
