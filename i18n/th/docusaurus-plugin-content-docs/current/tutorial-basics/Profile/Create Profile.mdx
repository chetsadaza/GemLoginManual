# การสร้างโปรไฟล์ (Create Profile)

เมนู **Create Profile** ใช้สำหรับสร้าง Browser Profile ใหม่ขึ้นมาในระบบ โดย GemLogin รองรับวิธีการสร้างหลากหลายรูปแบบตามความเหมาะสมของการใช้งาน

---

## รูปแบบการสร้างโปรไฟล์ (Create Mode)

ภายในเมนู Create Profile มีโหมดให้เลือกใช้งาน 4 รูปแบบหลัก ดังนี้:

| โหมด (Mode) | คำอธิบาย |
| :--- | :--- |
| **Single Create** | สร้างโปรไฟล์ทีละ 1 รายการ (ปรับแต่งค่าเชิงลึกได้ละเอียดที่สุด) |
| **Multiple Create** | สร้างโปรไฟล์ครั้งละหลาย ๆ รายการพร้อมกัน |
| **Import File** | นำเข้าข้อมูลโปรไฟล์จากไฟล์ Excel (.xlsx / .csv) |
| **Import from External** | สแกนและนำเข้าโปรไฟล์จากระบบภายนอก หรือโปรไฟล์ Chrome ที่มีอยู่เดิมในเครื่อง |

---

## Single Create

**Single Create** เหมาะสำหรับการสร้าง Browser Profile รายตัวที่ต้องการกำหนดค่าเฉพาะเจาะจง:

* ปรับแต่งค่าโปรไฟล์แบบกำหนดเอง (Custom)
* กำหนดค่า Fingerprint ขั้นสูงอย่างละเอียด
* ทดสอบการตั้งค่าเครือข่าย Proxy รายตัว

---

### ภาพรวมการตั้งค่า (Overview)

ส่วน **Overview** เป็นการกำหนดค่าพื้นฐานและมีความสำคัญที่สุดต่อการสร้างลายนิ้วมือเบราว์เซอร์ (Fingerprint)

ค่าต่าง ๆ ในส่วนนี้ใช้ระบุเอกลักษณ์ของ Browser เช่น:
* ระบบปฏิบัติการ (Operating System)
* เวอร์ชันเบราว์เซอร์ (Browser Version)
* ภาษา (Language)
* โซนเวลา (Timezone)
* พิกัดตำแหน่ง (Geolocation)
* User-Agent

> [!IMPORTANT]
> ค่าต่าง ๆ ในส่วน Overview ควรสอดคล้องกันทั้งหมด มิฉะนั้นระบบตรวจจับของเว็บไซต์อาจมองว่าเป็นพฤติกรรมที่น่าสงสัย

---

#### Name (ชื่อโปรไฟล์)
ใช้กำหนดชื่อสำหรับโปรไฟล์

**ข้อแนะนำ:**
* ตั้งชื่อให่านง่ายและสื่อความหมาย
* แยกตามประเภทของงานหรือแพลตฟอร์ม
* ค้นหาและจัดหมวดหมู่ได้สะดวก

```bash id="m8l2x1"
FB_TH_01
TikTok_VN_01
Google_Work_01
```

---

#### Group (กลุ่มโปรไฟล์)
ใช้จัดหมวดหมู่ให้กับโปรไฟล์เพื่อความเป็นระเบียบ

```bash id="e2f7v9"
Facebook
TikTok
Google
Warm
Testing
```

---

#### Operating System (ระบบปฏิบัติการ)
เลือกระบบปฏิบัติการที่ต้องการจำลอง:

| อุปกรณ์ที่ใช้จริง | ค่า OS ที่แนะนำให้เลือก |
| :--- | :--- |
| Windows PC | `Win10` / `Win11` |
| MacBook | `MacOS` |
| สมาร์ตโฟน Android | `Android` |
| iPhone / iPad | `iOS` |

```diff id="q7f4b2"
+ เลือก OS ให้สอดคล้องกับสภาพแวดล้อมอุปกรณ์เครื่องจริง
+ ใช้งาน OS เดิมอย่างต่อเนื่องเพื่อรักษาความน่าเชื่อถือของบัญชี
```

```diff id="f2s8m4"
- สลับเปลี่ยน OS ไปมาอย่างไร้เหตุผล
- ใช้งานค่า OS ที่ไม่สอดคล้องกับฮาร์ดแวร์จริง
```

---

#### Browser & Version (เบราว์เซอร์และเวอร์ชัน)
แนะนำให้เลือกใช้ **Chrome** เนื่องจากรองรับเว็บส่วนใหญ่ มีความเสถียรสูง และ Fingerprint ดูเป็นธรรมชาติ

**เวอร์ชันที่แนะนำ:**
```bash id="u6m2w7"
138
139
140
141
```

---

#### URL Startup (หน้าเว็บเริ่มต้น)
กำหนด URL เว็บไซต์ที่ต้องการให้เปิดขึ้นมาโดยอัตโนมัติเมื่อสั่งรันโปรไฟล์

```bash id="v4n8x2"
https://google.com
https://youtube.com
https://facebook.com
```

*ช่วยให้พฤติกรรมการเปิดเบราว์เซอร์ดูเป็นธรรมชาติ ลดความเสี่ยงจากการเปิดตรงเข้าหน้า Login ทันที*

---

#### User-Agent
ชุดข้อมูลระบุตัวตนของเบราว์เซอร์ที่ส่งไปยังเซิร์ฟเวอร์ปลายทาง

**แนะนำให้ตั้งค่าเป็น:**
```bash id="b1x4v8"
Auto
```
*ระบบจะคำนวณและจับคู่ Browser, OS และ Version ให้สัมพันธ์กันโดยอัตโนมัติ*

---

#### Select Country (ประเทศ)
เลือกประเทศให้ตรงกับพิกัดของ Proxy / IP ที่ใช้งาน

| Proxy | ประเทศที่ควรเลือก |
| :--- | :--- |
| Thailand | Thailand (ไทย) |
| Vietnam | Vietnam (เวียดนาม) |
| USA | United States (สหรัฐอเมริกา) |

---

#### Timezone & Language (โซนเวลาและภาษา)
กำหนด Timezone และภาษาให้ตรงกับประเทศของ Proxy:

| ประเทศ | โซนเวลา (Timezone) | ภาษาที่แนะนำ |
| :--- | :--- | :--- |
| Thailand | `Asia/Bangkok` | Thai, English |
| Vietnam | `Asia/Ho_Chi_Minh` | Vietnamese, English |
| Japan | `Asia/Tokyo` | Japanese, English |

---

### Network (การตั้งค่าเครือข่ายและ Proxy)

#### รูปแบบ Proxy ที่รองรับ:
* **Proxy Type**: `SOCKS5` (แนะนำ), `HTTP`, `HTTPS`
* **Format**: `host:port:username:password` หรือ `host:port`
* **ปุ่ม Check**: กดเพื่อทดสอบการเชื่อมต่อ IP ก่อนบันทึกโปรไฟล์

---

### Cookies (การจัดการคุกกี้)
รองรับการนำเข้า (Import), ส่งออก (Export) และบันทึกคุกกี้อัตโนมัติ (Auto Save Cookies) เพื่อคงสถานะการล็อกอินบัญชีอย่างต่อเนื่อง

---

### Advanced Settings (การตั้งค่าขั้นสูง)
สำหรับปรับแต่ง Fingerprint เชิงลึก:
* Canvas Noise & WebGL
* Audio Context
* Fonts & Hardware Concurrency
* Device Memory

---

## Multiple Create

ใช้สำหรับสร้าง Browser Profile ทีละหลาย ๆ รายการพร้อมกัน เหมาะสำหรับงานที่ต้องเตรียมโปรไฟล์จำนวนมาก

### ขั้นตอนการใช้งาน:
1. กำหนดจำนวนโปรไฟล์ในช่อง **Number of profiles** (เช่น `5`, `10`, `50`)
2. เลือกกลุ่ม **Group**
3. เลือกการตั้งค่าเบราว์เซอร์ใน **Browser configuration**
4. (ตัวเลือกเสริม) เปิดใช้งาน **Create Random Operating System** เพื่อสุ่ม OS กระจายความเสี่ยง
5. คลิกปุ่ม **Create profiles** เพื่อเริ่มการสร้าง

---

## Import File

สร้างโปรไฟล์พร้อมกันผ่านการอัปโหลดไฟล์ตารางสเปรดชีต (`.xlsx` หรือ `.csv`)

### โครงสร้างคอลัมน์ในไฟล์:
* **Name**: ชื่อโปรไฟล์ (จำเป็นต้องระบุ)
* **Proxy**: ข้อมูลพร็อกซีในรูปแบบ `ip:port:username:password`
* **User-Agent**: ข้อมูล User-Agent ที่ต้องการระบุเฉพาะ (ถ้ามี)
* **Cookie**: ชุดข้อมูลคุกกี้เริ่มต้น

---

## Import from External

สแกนและดึงโปรไฟล์ Chrome ที่มีอยู่เดิมในเครื่องเข้ามาในระบบ GemLogin

### ขั้นตอนการใช้งาน:
1. ระบุโฟลเดอร์ User Data ของ Chrome ในช่อง `Enter path to file chrome` (หรือกดไอคอนโฟลเดอร์ 📁)
2. เลือกรายการโปรไฟล์ที่ต้องการนำเข้าจากตาราง `List profiles`
3. ตั้งค่า `Concurrent Threads` (จำนวนเธรดการประมวลผลพร้อมกัน)
4. คลิกปุ่ม **Import** เพื่อนำเข้าโปรไฟล์เข้าสู่ระบบ
