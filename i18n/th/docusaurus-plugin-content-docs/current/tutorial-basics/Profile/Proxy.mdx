# การจัดการพร็อกซีประจำโปรไฟล์ (Proxy Management)

การตั้งค่าเครือข่าย **Proxy** ในแต่ละโปรไฟล์ เพื่อจำลองที่อยู่ IP และตำแหน่งทางภูมิศาสตร์ให้ตรงกับประเทศเป้าหมาย

---

## รูปแบบการเชื่อมต่อ Proxy

| รูปแบบ | คำอธิบาย |
| :--- | :--- |
| **SOCKS5** | โปรโตคอลแนะนำเพื่อความเสถียรและความปลอดภัยสูงสุด |
| **HTTP / HTTPS** | โปรโตคอลมาตรฐานทั่วไป |
| **Without Proxy (Direct)** | ใช้อินเทอร์เน็ตตรงจากเครื่องคอมพิวเตอร์ |

---

## รูปแบบการกรอกข้อมูล

```text
host:port:username:password
```
*(ตัวอย่าง: `192.168.1.1:8080:user01:pass01`)*

กดปุ่ม **Check Proxy** เพื่อทดสอบความเร็วและตรวจดูสถานะที่อยู่ IP จริงก่อนบันทึก
