# การจัดการทรัพยากรบัญชี (Resource Management)

ส่วน **Resource Management** ใช้สำหรับบันทึกและผูกข้อมูลบัญชีแพลตฟอร์มต่าง ๆ (เช่น Facebook, TikTok, Google, Shopee) เข้ากับโปรไฟล์เบราว์เซอร์นั้น ๆ

---

## คุณสมบัติหลัก

* **Account Type**: เลือกประเภทแพลตฟอร์มบัญชี
* **Credentials Storage**: บันทึก Username, Password และ 2FA Secret Key ประจำโปรไฟล์
* **Status Tracking**: ติดตามสถานะบัญชี (`Active`, `Inactive`, `Invalid`, `Checkpoint`)
