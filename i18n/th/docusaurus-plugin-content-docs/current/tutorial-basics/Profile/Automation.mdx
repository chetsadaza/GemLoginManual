# ระบบอัตโนมัติประจำโปรไฟล์ (Automation)

หน้า **Automation** ในส่วนตั้งค่าโปรไฟล์ ใช้สำหรับผูกสคริปต์อัตโนมัติให้ทำงานร่วมกับโปรไฟล์ทันทีเมื่อรันงาน

---

## ฟังก์ชันหลัก

* **Select Workflow**: เลือกสคริปต์ Workflow ที่ต้องการผูกเข้ากับโปรไฟล์นี้
* **Auto Run on Launch**: เปิดตัวเลือกสั่งให้สคริปต์ทำงานทันทีที่เปิดเบราว์เซอร์โปรไฟล์ขึ้นมา
* **Custom Parameters**: กำหนดค่าตัวแปรป้อนเข้า (Input Parameters) เฉพาะสำหรับโปรไฟล์นี้
