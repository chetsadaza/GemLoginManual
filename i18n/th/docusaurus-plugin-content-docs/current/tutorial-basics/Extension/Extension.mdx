# การจัดการส่วนขยาย (Extension Management)

โมดูล **Extension** ใน GemLogin ใช้สำหรับติดตั้งและจัดการส่วนขยายเบราว์เซอร์ (Chrome Extensions) ให้กับโปรไฟล์ทั้งหมด สามารถติดตั้งจาก Store สำเร็จรูป หรืออัปโหลดไฟล์แพ็กเกจ `.crx` / `.zip` ของตนเองได้

---

## 1. Manage Extension (จัดการส่วนขยายที่ติดตั้งแล้ว)

แสดงรายการส่วนขยายทั้งหมดในระบบ:

* **ช่องค้นหา (Search)**: ค้นหาส่วนขยายตามชื่อ
* **สวิตช์ เปิด/ปิด (Toggle Switch)**: เปิดหรือปิดการทำงานของส่วนขยายสำหรับโปรไฟล์
* **ปุ่มรีเฟรช (Reload Icon)**: ซิงก์อัปเดตเวอร์ชันส่วนขยายล่าสุด

---

## 2. Store Extension (ร้านค้าส่วนขยาย)

คลังส่วนขยายยอดนิยมที่จัดเตรียมไว้ให้ติดตั้งได้ทันทีด้วยคลิกเดียว:

* ค้นหาและกดปุ่ม **Add** เพื่อติดตั้งเข้าสู่ระบบ
* แสดงคะแนนเรตติ้งและรายละเอียดการใช้งาน

---

## 3. Custom Extension Upload (อัปโหลดส่วนขยายเอง)

คลิกที่ปุ่ม **Upload** (ไอคอนลูกศรชี้ขึ้น `^`) เพื่อติดตั้งส่วนขยายที่ไม่มีในคลัง:

* **ไฟล์ CRX / ZIP**: เลือกเส้นทางไฟล์ส่วนขยายจากเครื่องคอมพิวเตอร์
* **URL Import**: วางลิงก์ URL ของไฟล์แพ็กเกจส่วนขยายออนไลน์
