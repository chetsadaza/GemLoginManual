# การจัดการสมาชิกทีม (Members Settings)

แผง **Members Settings** สำหรับจัดการสิทธิ์ทีมงาน เชิญสมาชิกเข้าใช้งานร่วม และแชร์ Browser Profile ภายในองค์กร

> [!IMPORTANT]
> ฟังก์ชันการทำงานร่วมกันเป็นทีมใช้งานได้เฉพาะแพ็กเกจพรีเมียม (Paid Plan) เท่านั้น
