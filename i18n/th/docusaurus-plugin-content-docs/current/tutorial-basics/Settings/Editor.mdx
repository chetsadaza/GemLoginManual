# การตั้งค่าหน้าแก้ไขสคริปต์ (Editor Settings)

แผง **Editor Settings** ใช้ปรับแต่งพฤติกรรมของหน้าจอแก้ไขสคริปต์ Visual Canvas Editor

---

## หัวข้อการตั้งค่า

* **Min / Max zoom**: กำหนดขีดจำกัดการย่อขยายหน้าจอ Canvas
* **Line arrow**: แสดงหัวลูกศรชี้ทิศทางบนเส้นเชื่อมต่อบล็อก
* **Snap to the grid**: จัดตำแหน่งบล็อกคำสั่งให้ลงล็อกตาราง grid อัตโนมัติ
* **Auto-save**: บันทึกสคริปต์อัตโนมัติเมื่อกดสั่งรันงาน
