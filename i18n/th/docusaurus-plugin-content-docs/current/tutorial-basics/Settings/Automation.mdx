# การตั้งค่าระบบอัตโนมัติ (Automation Settings)

แผง **Automation Settings** สำหรับกำหนดค่ามาตรฐานส่วนกลางเมื่อรันสคริปต์อัตโนมัติ

---

## หัวข้อการตั้งค่าหลัก

* **Auto-delete workflow logs**: กำหนดระยะเวลาลบประวัติ Log อัตโนมัติ (เช่น 60 วัน)
* **Number of concurrent threads**: จำนวนโปรไฟล์ที่จะสั่งรันพร้อมกันโดยเฉลี่ย
* **Window size**: จัดเรียงขนาดหน้าต่างเบราว์เซอร์บนหน้าจอแบบตาราง (เช่น 2 แถว x 5 คอลัมน์)
* **Open time between profiles (ms)**: ระยะเวลาหน่วงเว้นช่วงการเปิดแต่ละโปรไฟล์ (มิลลิวินาที)
* **Close browser after completion**: ปิดเบราว์เซอร์อัตโนมัติเมื่อรันสคริปต์เสร็จสิ้น
