# คีย์ลัดระบบ (Keyboard Shortcuts)

การใช้งานคีย์ลัดช่วยให้สามารถสลับหน้าจอและสั่งงานสคริปต์ได้อย่างรวดเร็ว

---

## คีย์ลัดสลับหน้าจอ (Navigation Shortcuts)

| หน้าเป้าหมาย | คีย์ลัด (Shortcut) |
| :--- | :--- |
| **Profile** | `Alt + 1` |
| **Workflows** | `Alt + 2` |
| **Marketplace** | `Alt + 3` |
| **Package** | `Alt + 4` |
| **Extension** | `Alt + 5` |
| **Logs** | `Alt + 8` |
| **Settings** | `Alt + 0` |

---

## คีย์ลัดในหน้าแก้ไขสคริปต์ (Workflow Editor)

| การทำงาน | คีย์ลัด (Shortcut) |
| :--- | :--- |
| **คัดลอกบล็อกคำสั่ง** | `Ctrl + Alt + D` |
| **ค้นหาบล็อก** | `Ctrl + B` |
| **บันทึกสคริปต์** | `Ctrl + S` |
| **สั่งรันสคริปต์** | `Alt + Enter` |
