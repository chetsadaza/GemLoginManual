# การตั้งค่าทั่วไป (General Settings)

แผง **General Settings** ใช้สำหรับตั้งค่าการแสดงผลของโปรแกรม จัดการดาวน์โหลดคอร์เบราว์เซอร์ และเลือกตำแหน่งโฟลเดอร์สำหรับจัดเก็บโปรไฟล์ในคอมพิวเตอร์

---

## 1. Interface Preferences (ธีมและภาษา)

* **Theme**: เลือกธีมการแสดงผล (`Light` / `Dark`)
* **Language**: เลือกภาษาการใช้งานเมนูกรอบโปรแกรม (`English`, `Thai`)

---

## 2. Browser Engine Management (จัดการคอร์เบราว์เซอร์)

ดาวน์โหลด ติดตั้งใหม่ หรือล้างไฟล์ขยะของเบราว์เซอร์เอนจินหลัก

> [!WARNING]
> ปิดเบราว์เซอร์โปรไฟล์ที่กำลังทำงานทั้งหมดก่อนกดติดตั้งหรืออัปเดตเวอร์ชันเอนจิน

* **Browser & Version**: เลือกประเภทและเวอร์ชันของเบราว์เซอร์ที่ต้องการจัดการ (เช่น `Chrome 141`)
* **Clean profiles folder**: ลบแคชชั่วคราวและไฟล์ค้างในเอนจินเบราว์เซอร์เพื่อคืนพื้นที่ดิสก์

---

## 3. Storage Location (ตำแหน่งจัดเก็บไฟล์)

กำหนดพาธโฟลเดอร์ที่ใช้เก็บบันทึกโปรไฟล์ทั้งหมดในเครื่อง (เช่น `D:\Apps\Profiles`)
* **Use selected path**: เปลี่ยนไปใช้พาธโฟลเดอร์ใหม่
* **Copy profiles to selected path**: คัดลอกโปรไฟล์เดิมทั้งหมดไปยังโฟลเดอร์ใหม่
