# การจัดการสคริปต์เวิร์กโฟลว์ (Workflows)

เมนู **Workflows** เป็นศูนย์กลางสร้าง ออกแบบ และแก้ไขสคริปต์ระบบอัตโนมัติ (Automation Workflows) ผ่านเครื่องมือ **Visual Canvas Editor** ที่ช่วยให้สร้างสคริปต์ได้ง่ายด้วยการลากและวางบล็อกคำสั่ง

---

## ฟีเจอร์หลักใน Workflows

* **+ Create Workflow**: สร้างสคริปต์การทำงานใหม่
* **Visual Editor**: ตัวแก้ไขแบบผังภาพ ลากบล็อกเชื่อมต่อเส้นไหลของงาน (Flowchart Style)
* **Import / Export Script**: นำเข้าและส่งออกสคริปต์ไฟล์ `.json` เพื่อแชร์สคริปต์ให้ทีมงาน
* **Template Marketplace**: คลังสคริปต์สำเร็จรูปที่ดาวน์โหลดนำมาใช้งานได้ทันที
