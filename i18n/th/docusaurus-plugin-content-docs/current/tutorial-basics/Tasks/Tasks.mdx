# การจัดการงาน (Tasks Management)

เมนู **Tasks** ใช้สำหรับสร้างชุดงานอัตโนมัติ โดยนำสคริปต์ Workflow มาสั่งรันร่วมกับกลุ่มโปรไฟล์เบราว์เซอร์ที่ต้องการ พร้อมรองรับการตั้งเวลาการรันล่วงหน้า

---

## ขั้นตอนการสร้าง Task

1. **+ Create Task**: คลิกปุ่มสร้างงานใหม่
2. **Select Workflow**: เลือกสคริปต์ Automation ที่ต้องการรัน
3. **Select Profiles**: เลือกโปรไฟล์หรือกลุ่มโปรไฟล์ที่ใช้ในการรันงาน
4. **Task Configuration**:
   * **Threads**: กำหนดจำนวนโปรไฟล์ที่จะรันพร้อมกัน
   * **Repeat**: ตั้งจำนวนรอบการรันซ้ำ
   * **Delay**: ตั้งเวลาเว้นระยะการเปิดโปรไฟล์
5. **Start / Schedule**: กดสั่งรันงานทันที หรือตั้งเวลารันอัตโนมัติ
