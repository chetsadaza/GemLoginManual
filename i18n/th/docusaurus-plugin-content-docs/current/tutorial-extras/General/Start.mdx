# Start Workflow

Example workflow demonstrating the **Start (Trigger)** block equipped with **Parameters** to build interactive UI input forms before starting execution. Connected to **Open URL** to launch the target webpage.

## Interactive Workflow Preview

Click on blocks to view and edit settings. Drag background to pan, use scroll wheel to zoom in/out.

<WorkflowPreview data={startData} height={580} />

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point with Parameters for building user input forms. |
| **Open URL** | `BlockBasicWithFallback` | Opens the target webpage (`facebook.com` in this example). |

## Start Block Parameter Settings

The **Start** block allows building dynamic UI input forms to capture user parameters before automation starts. Click **⌘ Parameters** inside the settings panel to open the parameter designer.

### Data Input Types

| Parameter Type | Description | Inputs | Sample Output Format |
| :--- | :--- | :--- | :--- |
| **Checkbox** | Boolean toggle switch (`true` / `false`) | <ul><li>**Name**: `enable_proxy`</li><li>**Label**: `Enable Proxy`</li><li>**Default**: Checked = `true` / Unchecked = `false`</li></ul> | `{"enable_proxy": true}` |
| **File Path** | System file path picker input | <ul><li>**Name**: `cookie_file`</li><li>**Label**: `Cookie File`</li><li>**Placeholder**: `C:/cookies/account1.json`</li></ul> | `"C:/Users/Admin/Desktop/cookies.json"` |
| **Input (JSON)** | Accepts JSON Object payloads | <ul><li>**Name**: `config`</li><li>**Label**: `Config`</li><li>**Default**: Initial Object schema</li></ul> | `{"proxy": {"host": "1.1.1.1", "port": 8080}, "headless": true}` |
| **Input (number)** | Numeric values only (delay, timeout, retry count) | <ul><li>**Name**: `delay`</li><li>**Label**: `Delay`</li><li>**Default**: `5`</li></ul> | `10` |
| **Input (string)** | Text strings (email, password, token, url, text) | <ul><li>**Name**: `username`</li><li>**Label**: `Username`</li><li>**Placeholder**: `Enter username`</li></ul> | `"admin123"` |

### UI Layout Components

* **Divider**: Visual separator for parameter groups.
  * **Usage**: Set **Divided label** (e.g. `Account Setting`).
* **Spacer**: Vertical spacing between UI elements.
* **Label**: Informational text or helper hints on the input form.
  * **Usage**: Specify text in **Label** field (e.g. `Please fill all required fields`).

* **Divider**: `Login Form`
* **Input (string)**: `username`

### Execution Flow

1. **Start (Trigger)** — Displays parameter form and initializes workflow data.
2. **Open URL** — Opens browser window to target URL `https://www.facebook.com/`.
