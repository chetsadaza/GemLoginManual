Example workflow demonstrating the **Delay** block, used to pause execution for a specified duration (in milliseconds) before proceeding to the next block. Connected from **Start (Trigger)** to **Open URL** and then **Delay**.

| Block | Type | Description |
|-------|------|-------------|

## Delay Block Settings

The **Delay** block pauses workflow execution temporarily. Useful for pacing actions, waiting for page loads, or mimicking human timing behavior.

### Parameters

| Parameter | Description | Default |
| :--- | :--- | :--- |
| **Time (ms)** | Delay duration in milliseconds (1000 ms = 1 second) | `5000` |

### Usage Examples

| Time (ms) Value | Duration | Use Case |
| :--- | :--- | :--- |
| `1000` | 1 second | Short pause between button clicks |
| `3000` | 3 seconds | Wait for background AJAX request completion |
| `5000` | 5 seconds | Wait for page DOM & assets to render |
| `10000` | 10 seconds | Extended pause for human behavior simulation |

---

### When to Use Delay

* **Page Load Buffer**: Place Delay after Open URL to ensure dynamic content renders completely.
* **Anti-Detection**: Space out automated actions to mimic human interaction rhythms.
* **API Throttling**: Pause between API calls to prevent rate-limit penalties.

---

### Execution Flow

1. **Start (Trigger)** — Loads parameters and initializes workflow.
2. **Open URL** — Opens `https://www.facebook.com/` in browser tab.
3. **Delay** — Pauses execution for `5000 ms` (5 seconds) before proceeding.
