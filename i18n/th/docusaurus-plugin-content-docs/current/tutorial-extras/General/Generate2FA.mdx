# Generate 2FA Workflow

Example workflow demonstrating the **Generate 2FA** block, used to compute Time-Based One-Time Passwords (TOTP) from a Secret Key for two-factor authentication (2FA) logins. Connected from **Start (Trigger)** to **Open URL** and then passing data to **Generate 2FA**.

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point with Parameters for building user input forms. |
| **Open URL** | `BlockBasicWithFallback` | Opens the target webpage (`facebook.com` in this example). |
| **Generate 2FA** | `BlockBasicWithFallback` | Computes and generates a 6-digit TOTP code from a Secret Key at runtime. |

## Generate 2FA Block Settings

The **Generate 2FA** block converts a 2-factor secret key into a live 6-digit TOTP authentication code automatically.

### Parameters

| Parameter | Description | Details |
| :--- | :--- | :--- |
| **Generate 2FA** | Secret Key string for the target 2FA service | 16-32 character secret key (e.g. `JBSWY3DPEHPK3PXP`), supports `{{variables}}` |
| **Assign to variable** | Save generated TOTP to a variable | Toggle On/Off (Boolean) |
| **Variable name** | Variable name to store the 6-digit TOTP | e.g., `totp_code` |
| **Timeout** | Maximum execution duration (ms) | In milliseconds (e.g. `5000` ms) |
| **Delay time** | Delay before executing (ms) | In milliseconds (e.g. `1000` ms = 1 second) |

---

### Use Cases

* **Automated 2FA Logins**: Automatically complete 2-factor authentication prompts (Facebook, Google, GitHub) after filling credentials.
* **API or Bot Authorization**: Generate OTPs on demand for sensitive API transactions or administrative bot workflows.

---

### Execution Flow

1. **Start (Trigger)** — Initializes workflow and loads parameters.
2. **Open URL** — Navigates browser to `https://www.facebook.com/`.
3. **Generate 2FA** — Computes the 6-digit TOTP from the Secret Key for immediate use in login fields.
