# Workflow State Workflow

Example workflow demonstrating the **Workflow State** block, used to control execution states of active workflows within the system. Allows stopping or signaling other running workflows or terminating the current workflow under specified conditions.

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point. |
| **Open URL** | `BlockBasicWithFallback` | Opens target webpage. |
| **Workflow State** | `BlockBasicWithFallback` | Controls and updates workflow execution states across the system. |

## Workflow State Block Settings

The **Workflow State** block provides execution control actions to manage script lifecycle.

### Main Parameters

| Parameter | Description | Options & Details |
| :--- | :--- | :--- |
| **Description** | Custom block label or note | Displayed in subtle italic text |
| **Action** | State management action | **Stop workflows** category: <br/>• `Stop all workflows` (terminates all active workflows)<br/>• `Stop current workflow` (terminates current execution context)<br/>• `Stop specific workflows` (terminates targeted workflows) |
| **Except current workflow** | Exclude current running workflow from termination | Visible when Action is set to `Stop specific workflows` |

### Settings Parameters

* **Timeout (millisecond)**: Maximum execution duration for this block.
* **Delay time (millisecond)**: Pre-execution delay before evaluating action.

---

### Use Cases

* **Error & Exception Handling**: Immediately halt execution (`Stop all workflows`) upon encountering critical unrecoverable errors.
* **Sequential Chain Control**: Terminate current sub-workflow and yield control to clear execution queues for new tasks.
