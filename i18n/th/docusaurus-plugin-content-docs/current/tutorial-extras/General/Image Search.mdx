# Image Search Workflow

Example workflow demonstrating the **Image Search** block, used to locate target images on the browser screen to retrieve coordinates or execute direct clicks (Image-based Automation). Connected from **Start (Trigger)** to **Open URL** and then passing data to **Image Search**.

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point with Parameters for building user input forms. |
| **Open URL** | `BlockBasicWithFallback` | Opens the target webpage (`facebook.com` in this example). |
| **Image Search** | `BlockBasicWithFallback` | Locates target images on screen using Computer Vision with coordinate output & auto-click options. |

## Image Search Block Settings

The **Image Search** block replaces traditional DOM selectors (XPath / CSS) with Computer Vision image recognition to locate buttons or graphical elements.

### Parameters

| Parameter | Description | Details |
| :--- | :--- | :--- |
| **Mode Dropdown** | Image reference format | `Path` (file path e.g. `C:/images/btn.png`) <br/> `Base64` (Base64 encoded image string) |
| **Image Path Input** | Input field for image path or Base64 string | Includes image picker 🖼️ button and variable insertion `{x}` |
| **Algorithm (Algo)** | Image matching algorithm | `Tpl` (Template Matching for exact pixel match) <br/> `Kaze` (Scale/rotation invariant feature matching) |
| **Take a screenshot of** | Screen capture area for image matching | `A page` (entire viewport) <br/> `An element` (specific bounding element) |
| **Click Image** | Auto-click center of image when found | Toggle On/Off (Boolean) |
| **RGB Enable** | Enable exact color spectrum matching (RGB) | Improves accuracy and prevents color shade confusion |
| **Threshold** | Detection sensitivity threshold (0.0 to 1.0) | e.g. `0.1` (lower values require stricter similarity) |
| **Coordinates Output Variables** | Variable names to store matched X, Y coordinates | Stores coordinates for downstream click actions |
| **Timeout** | Maximum search duration (ms) | In milliseconds (e.g. `5000` ms) |
| **Delay time** | Delay before starting search (ms) | In milliseconds (e.g. `1000` ms) |

---

### Use Cases

* **Click Dynamic / Canvas Buttons**: Click elements without stable DOM selectors, Canvas graphics, or Flash games.
* **UI Status Verification**: Verify status by searching for visual indicators (green checkmarks, loading spinners).
* **CAPTCHA / Pop-up Detection**: Locate overlay alert icons to auto-close interrupting popups.

---

### Execution Flow

1. **Start (Trigger)** — Initializes workflow and loads parameters.
2. **Open URL** — Navigates browser to `https://www.facebook.com/`.
3. **Image Search** — Scans viewport for target image, outputs coordinates, and executes click.
