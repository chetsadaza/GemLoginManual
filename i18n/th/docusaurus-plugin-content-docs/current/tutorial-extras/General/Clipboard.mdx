# Clipboard Workflow

Example workflow demonstrating the **Clipboard** block, used to manipulate systemic clipboard data (copying or retrieving text) to pass to downstream blocks or save into databases. Connected from **Start (Trigger)** to **Open URL** and ending at **Clipboard**.

Click on blocks to view and edit settings. Drag background to pan, use scroll wheel to zoom in/out.

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point with Parameters for building user input forms. |
| **Open URL** | `BlockBasicWithFallback` | Opens target webpage (`facebook.com` in this example). |
| **Clipboard** | `BlockBasicWithFallback` | Copies text (Set) or reads text (Get) from system clipboard. |

## Clipboard Block Settings

The **Clipboard** block operates in two primary modes: **Get** (read from clipboard) and **Set** (write to clipboard).

### Parameters

| Parameter | Description | Details |
| :--- | :--- | :--- |
| **Type** | Operation mode | `get` (Read) / `set` (Write) |
| **Assign variable** | Assign clipboard contents to variable | Enable to save output as system variable |
| **Variable name** | Output variable identifier | e.g., `clipboard_text` |
| **Save data** | Save data into script database table | Toggle On/Off (Boolean) |
| **Data column** | Database table column target | Select column defined in Database settings |
| **Data to copy** | Text string to copy to clipboard (for `Set` mode) | Supports literal text or `{{variables}}` |
| **Copy selected text** | Copy highlighted webpage text selection | Simulates `Ctrl + C` on selected webpage elements |
| **Delay** | Pre-execution delay duration (ms) | In milliseconds (e.g. `500` ms) |

---

### Use Cases

* **Get Mode (Read from Clipboard)**:
    * Retrieve 2FA / OTP codes or authentication links copied from external apps.
    * Read API keys or access tokens to pass to downstream automation blocks.
* **Set Mode (Write to Clipboard)**:
    * Copy preset comment templates, messages, or credentials for paste actions.
    * Prepare data payloads for quick multi-field pasting operations.

---

### Execution Flow

1. **Start (Trigger)** — Loads parameters and initializes workflow.
2. **Open URL** — Opens `https://www.facebook.com/` in browser.
3. **Clipboard** — Performs clipboard operation (Get or Set) based on block configuration.
