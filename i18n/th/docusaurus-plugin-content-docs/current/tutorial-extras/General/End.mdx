# End Workflow

The **End** block is the terminal execution node for a workflow. It connects as the final step in an automation sequence.

## End Block Details

The **End** block marks the conclusion of the entire automation script. When execution reaches this block, the script terminates immediately with a Success status.

### Settings

* **Description**: Short label or note for internal workflow documentation.
* *Note: The End block is a terminal node and has no output ports to connect to downstream blocks.*

### Use Cases

* **Successful Termination**: Placed at the end of a workflow sequence to explicitly mark completion.
* **Conditional Stop**: Used with Condition blocks to terminate execution early when specific criteria are met.
* **Loop Termination**: Exit loop structures upon reaching target outcomes.
