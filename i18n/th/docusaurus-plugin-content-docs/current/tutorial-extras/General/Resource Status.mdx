# Resource Status Workflow

Example workflow demonstrating the **Resource Status** block, used to categorize and update the status of target account profiles or system resources (Resource Status Management) across platforms such as Facebook, TikTok, YouTube, Shopee, Zalo, and Google. Connected from **Start (Trigger)** to **Open URL** and followed by **Resource Status**.

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point with Parameters for building user input forms. |
| **Open URL** | `BlockBasicWithFallback` | Opens the target webpage (`facebook.com` in this example). |
| **Resource Status** | `BlockBasicWithFallback` | Updates account and resource status levels across platforms with custom note logs. |

## Resource Status Block Settings

The **Resource Status** block allows tagging account health and categorizing dynamic resource states for operational reporting.

### Parameters

| Parameter | Description | Details |
| :--- | :--- | :--- |
| **Resource type** | Online platform or service target | `Facebook`, `Tiktok`, `Youtube`, `Shopee`, `Instagram`, `Twitter`, `Telegram`, `Zalo`, `Google`, `Outlook` |
| **Action Selector** | Recording mode | `Status` (log activity status) <br/> `Resource` (log primary resource level) |
| **Status type** | Account status label | `Active` (ready) <br/> `Inactive` (paused) <br/> `Invalid` (banned/invalid credentials) <br/> `Unknown` (unverified) |
| **Note type** | Custom status note or error reason | Supports text input or variable interpolation `{x}` (e.g. `{{variables.error_reason}}`) |
| **Timeout** | Maximum execution duration (ms) | In milliseconds (e.g. `5000` ms) |
| **Delay time** | Delay before executing (ms) | In milliseconds (e.g. `1000` ms = 1 second) |

---

### Use Cases

* **Bot Account Management**: Mark accounts as `Invalid` with detailed log notes when encountering checkpoints or auth failures.
* **Batch Task Tracking**: Flag accounts as `Active` upon successful completion of form submissions or warming workflows.
* **Auto Error Logging**: Aggregate operational health status across multi-account automation farms.

---

### Execution Flow

1. **Start (Trigger)** — Initializes workflow and loads input parameters.
2. **Open URL** — Navigates browser to `https://www.facebook.com/`.
3. **Resource Status** — Updates the target platform resource status (e.g., Facebook) and saves custom logs.
