# Cmd Workflow

Example workflow demonstrating the **Cmd** block, which executes system shell commands or OS script commands to control external tools or processes. Connected from **Start (Trigger)** to **Open URL** and then passing data to **Cmd**.

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point with Parameters for building user input forms. |
| **Open URL** | `BlockBasicWithFallback` | Opens the target webpage (`facebook.com` in this example). |
| **Cmd** | `BlockBasicWithFallback` | Executes system shell commands and extracts execution output into variables. |

## Cmd Block Settings

The **Cmd** block allows executing OS command-line instructions and capturing `stdout` output into workflow variables.

### Parameters

| Parameter | Description | Details |
| :--- | :--- | :--- |
| **Command** | Command string to execute | e.g. `echo "Hello GemLogin"`, Node.js, Python, or CLI commands |
| **Assign to variable** | Save output to variable | Toggle On/Off (Boolean) |
| **Variable name** | Variable name to store output | e.g., `cli_output` |
| **Regular expression (Regex)** | Pattern to extract specific output substring | e.g., `\d+` to extract numbers from CLI output |
| **Timeout** | Maximum execution duration (ms) | In milliseconds (e.g. `5000` ms) |
| **Delay time** | Delay before executing (ms) | In milliseconds (e.g. `1000` ms = 1 second) |

---

### Use Cases

* **Run External Scripts**: Call Python or Batch scripts to preprocess CSV/Excel data before opening the browser.
* **Network Health Check**: Execute `ping` or `curl` commands to verify connectivity before proceeding.
* **System Info Extraction**: Retrieve Hostname or IP address to store in automation variables.
* **System Control**: Execute commands to clean up temp files or trigger local applications.

---

### Execution Flow

1. **Start (Trigger)** — Initializes workflow and loads input parameters.
2. **Open URL** — Navigates browser to `https://www.facebook.com/`.
3. **Cmd** — Executes the command line instruction and stores output in variable.
