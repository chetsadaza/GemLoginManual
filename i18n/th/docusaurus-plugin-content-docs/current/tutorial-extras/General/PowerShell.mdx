# PowerShell Workflow

Example workflow demonstrating the **PowerShell** block, used to execute Microsoft Windows PowerShell scripts and cmdlets to control OS features and system services. Connected from **Start (Trigger)** to **Open URL** and then passing data to **PowerShell**.

Click on blocks to view and edit settings. Drag background to pan, use scroll wheel to zoom in/out.

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point with Parameters for building user input forms. |
| **Open URL** | `BlockBasicWithFallback` | Opens the target webpage (`facebook.com` in this example). |
| **PowerShell** | `BlockBasicWithFallback` | Executes Windows PowerShell cmdlets and extracts stdout output into variables. |

## PowerShell Block Settings

The **PowerShell** block provides direct execution of Microsoft Windows system administration cmdlets.

### Parameters

| Parameter | Description | Details |
| :--- | :--- | :--- |
| **Command** | PowerShell script or cmdlet string | e.g. `Get-Process`, `Get-Service`, or `.ps1` script execution |
| **Assign to variable** | Save stdout response to a variable | Toggle On/Off (Boolean) |
| **Variable name** | Variable name to store output | e.g., `ps_output` |
| **Regular expression (Regex)** | Pattern to extract specific substring | e.g., `\b[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}\b` for email extraction |
| **Timeout** | Maximum execution duration (ms) | Prevents script hanging on OS operations |
| **Delay time** | Delay before executing (ms) | In milliseconds (e.g. `1000` ms) |

---

### Use Cases

* **System Administration & Inspection**: Run PowerShell commands to inspect active processes (`Get-Process`) or system updates (`Get-HotFix`).
* **Advanced File Management**: Execute file manipulation, compression (Zip), or directory preparation before browser upload tasks.
* **OS Automation Interop**: Trigger native Windows automation tools or low-level API operations alongside browser actions.

---

### Execution Flow

1. **Start (Trigger)** — Initializes workflow and loads input parameters.
2. **Open URL** — Navigates browser to `https://www.facebook.com/`.
3. **PowerShell** — Executes PowerShell cmdlet script and outputs results to variable.
