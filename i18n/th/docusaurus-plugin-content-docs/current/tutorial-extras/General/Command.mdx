# Command Workflow

Example workflow demonstrating the **Command** block, used to execute system commands via specified command executors (Cmd, Terminal, or PowerShell) to manage external tools or capture shell output. Connected from **Start (Trigger)** to **Open URL** and then **Command**.

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point with Parameters for building user input forms. |
| **Open URL** | `BlockBasicWithFallback` | Opens target webpage (`facebook.com` in this example). |
| **Command** | `BlockBasicWithFallback` | Executes system shell instructions (Cmd/Terminal/PowerShell) and captures output. |

## Command Block Settings

The **Command** block provides multi-executor shell environment support across operating systems.

### Parameters

| Parameter | Description | Options & Details |
| :--- | :--- | :--- |
| **Command Executor** | Shell execution environment | `Cmd` (Windows Command Prompt) <br/> `Terminal` (macOS/Linux Bash/Zsh) <br/> `PowerShell` (Windows PowerShell) |
| **Command** | Command string to execute | Supports literal text or `{{variables}}` interpolation |
| **Assign to variable** | Save stdout execution response to a variable | Toggle On/Off (Boolean) |
| **Variable name** | Variable name to store output | e.g., `shell_output` |
| **Regular expression (Regex)** | Pattern to extract specific substring | e.g., `[a-zA-Z]+` to match English characters |
| **Timeout** | Maximum execution duration (ms) | Prevents hanging when scripts run continuously |
| **Delay time** | Delay before executing (ms) | In milliseconds (e.g. `1000` ms = 1 second) |

---

### Use Cases

* **Execute System Scripts**: Run external Python, Node.js, or Shell scripts prior to browser steps.
* **Cross-Platform Automation**: Switch executors dynamically (`Terminal` for macOS/Linux, `Cmd`/`PowerShell` for Windows).
* **Background Data Prep**: Execute file operations, directory creation, or local service checks before automation runs.

---

### Execution Flow

1. **Start (Trigger)** — Loads parameters and initializes workflow.
2. **Open URL** — Opens `https://www.facebook.com/` in browser tab.
3. **Command** — Executes specified system command and returns output.
