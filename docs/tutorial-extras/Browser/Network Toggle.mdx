# Network Toggle Workflow

Example workflow demonstrating the **Network Toggle** block, used to toggle browser internet connectivity (Online/Offline state) to test offline fallback behavior or block unwanted asset downloads during execution.

## Interactive Workflow Preview

Click on blocks to toggle connection state or select target tab scope. Drag background to pan.

<WorkflowPreview data={networkToggleData} height={580} />

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point. |
| **Open URL** | `BlockBasicWithFallback` | Opens target webpage. |
| **Network Toggle** | `BlockBasicWithFallback` | Toggles tab network connectivity state (Online/Offline). |

## Network Toggle Block Settings

### Main Parameters

| Parameter | Description | Options & Details |
| :--- | :--- | :--- |
| **Description** | Short block note | Frameless title header |
| **Scope** | Network toggle boundary | • `Active tab` (Currently focused tab)<br/>• `All tabs` (All browser tabs) |
| **Status Switch**| Target connectivity state | • `Close` (Offline mode / Disconnect network)<br/>• `Open` (Online mode / Enable network) |

### Settings Parameters

* **Timeout (millisecond)**: Maximum execution duration for this block.
* **Delay time (millisecond)**: Delay before toggling network status.

---

### Use Cases

* **Offline Mode Testing**: Simulate network drops or offline status to verify web application resilience and local storage fallbacks.
* **Asset Loading Suppression**: Toggle network state to `Close` immediately after main DOM load to prevent continuous background ad script downloads or resource draining.
