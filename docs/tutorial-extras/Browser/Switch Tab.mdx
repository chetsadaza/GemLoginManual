# Switch Tab Workflow

Example workflow demonstrating the **Switch Tab** block, used to locate and switch active focus to a target browser tab by URL pattern, tab title, tab index, or next/previous navigation.

## Interactive Workflow Preview

Click on blocks to edit tab selector criteria. Drag background to pan, scroll wheel to zoom in/out.

<WorkflowPreview data={switchTabData} height={580} />

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point. |
| **Open URL** | `BlockBasicWithFallback` | Opens target webpage. |
| **Switch Tab** | `BlockBasicWithFallback` | Switches active focus to target tab matching designated rules. |

## Switch Tab Block Settings

### Main Parameters

| Parameter | Description | Options & Details |
| :--- | :--- | :--- |
| **Select tab by** | Rule for targeting tab | `URL` (Match URL string)<br/>`Title` (Match tab title)<br/>`Index` (0-based index number)<br/>`Next` / `Previous` |
| **URL / Title Value** | Search pattern string | e.g. `facebook.com` or `Google Search`, supports `{x}` variables |

### Settings Parameters

* **Timeout (millisecond)**: Maximum search wait time for target tab to exist.
* **Delay time (millisecond)**: Delay before executing tab switch action.

---

### Use Cases

* **Multi-Tab Orchestration**: Switch focus to popup tabs launched by OAuth logins or payment gateways.
* **Batch Scraper Navigation**: Cycle through opened tabs sequentially using `Next` or `Index` rules.
