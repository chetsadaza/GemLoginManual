# Emulate Workflow

Example workflow demonstrating the **Emulate** block, used to emulate mobile devices (smartphones such as iPhone, Galaxy, and tablets such as iPad) for responsive layout testing and mobile user automation environments.

## Interactive Workflow Preview

Click on blocks to select device emulation presets. Drag background to pan, scroll wheel to zoom in/out.

<WorkflowPreview data={emulateData} height={580} />

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point. |
| **Open URL** | `BlockBasicWithFallback` | Opens target webpage. |
| **Emulate** | `BlockBasicWithFallback` | Emulates mobile device viewport, User-Agent, and touch parameters. |

## Emulate Block Settings

### Main Parameters

| Parameter | Description | Options & Details |
| :--- | :--- | :--- |
| **Description** | Short block note | Frameless header |
| **Device** | Preset target mobile device | Scrollable list e.g.:<br/>• `iPhone 11` (Default)<br/>• `iPhone X`, `iPhone 8/7/6 Plus`<br/>• `iPad Pro`, `iPad Mini`<br/>• `Galaxy S9+ / S5` |

### Settings Parameters

* **Timeout (millisecond)**: Maximum execution duration for this block.
* **Delay time (millisecond)**: Delay before initiating emulation mode.

---

### Use Cases

* **Responsive & Mobile Testing**: Render webpages in mobile screen viewports (`iPhone 11`) to verify responsive navigation and layout rendering.
* **Mobile-Only Workflows**: Access mobile-restricted features (e.g. mobile photo upload portals, lightweight mobile web views) by spoofing mobile User-Agent and viewport dimensions.
