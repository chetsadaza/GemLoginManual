# Wait Tab Load Workflow

The **Wait Tab Load** block pauses workflow execution until the active browser tab finishes loading completely before proceeding to downstream blocks.

Adding this block ensures robust execution by preventing "Element Not Found" errors caused by network latency or slow DOM rendering.

## Navigation States

1. **Load**: Waits for the standard `onload` event (HTML, CSS, JS, and all assets loaded).
2. **DOMContentLoaded**: Waits until the DOM tree is ready (ignores heavy assets like images/fonts for faster execution).
3. **Network Idle**: Waits until all background network connections cease (ideal for Single Page Applications using dynamic AJAX calls).

## Main Parameters

* **Timeout (millisecond)**: Maximum wait duration before raising a timeout exception (e.g., `30000` ms).
* **Delay time (millisecond)**: Additional buffer delay after load completion before resuming execution.

## Use Cases

* **Post Navigation / Form Submission**: Place after mouse clicks on login or submit buttons to wait for the next page load.
* **Script Robustness**: Prevents execution failures caused by asset loading delays.
