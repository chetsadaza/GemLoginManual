# Zoom Page Workflow

Example workflow demonstrating the **Zoom Page** block, used to adjust the viewport zoom level of a target web page. Useful for high-resolution screenshots or matching element scales for computer vision.

## Interactive Workflow Preview

Click on blocks to specify zoom size. Drag background to pan, scroll wheel to zoom preview in/out.

<WorkflowPreview data={zoomPageData} height={580} />

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point. |
| **Open URL** | `BlockBasicWithFallback` | Opens target webpage. |
| **Zoom Page** | `BlockBasicWithFallback` | Adjusts page zoom level by specified percentage. |

## Zoom Page Block Settings

### Main Parameters

| Parameter | Description | Options & Details |
| :--- | :--- | :--- |
| **Description** | Short block note or label | Frameless title header |
| **Zoom size** | Zoom level percentage | Default is `100` (100% normal scale), supports `{x}` variables |

### Settings Parameters

* **Timeout (millisecond)**: Maximum execution duration for this block.
* **Delay time (millisecond)**: Delay before executing zoom action.

### On Error Options

* **Enable Switch**: Toggle to bypass errors if zooming fails.

---

### Use Cases

* **High-Resolution Screenshotting**: Scale down page zoom (e.g. `75%` or `50%`) to capture wider viewport areas in single screenshot actions.
* **Element Match Alignment**: Align zoom levels when performing Image Search computer vision matching against static template samples.
