# Release Ram

The **Release Ram** block optimizes browser memory footprint by releasing allocated RAM used by open tabs, preventing browser slowdowns or memory exhaustion during long-running automation tasks.

---

## Main Parameters

### 1. Scope

Select memory release boundary:

* **Active Page**: Clears cache and releases RAM allocation specifically for the currently active tab.
* **All Page**: Purges memory across all open tabs (including background tabs) inside the browser session.

---

## Use Cases

* **Long-Running Workflows**: For workflows running continuously for hours or processing media-heavy websites (images, video streams, heavy JS assets).
* **Multi-Tab Tasks**: Release RAM on background tabs to maintain system stability during batch multi-tab operations.
