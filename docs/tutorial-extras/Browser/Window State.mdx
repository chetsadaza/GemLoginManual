# Window State Workflow

Example workflow demonstrating the **Window State** block, used to control browser window display states (minimize, normalize, maximize) during execution.

## Interactive Workflow Preview

Click on blocks to adjust window settings. Drag to pan, scroll wheel to zoom in/out.

<WorkflowPreview data={windowStateData} height={580} />

## Workflow Blocks

| Block | Type | Description |
|-------|------|-------------|
| **Start (Trigger)** | `BlockBasic` | Workflow entry point. |
| **Open URL** | `BlockBasicWithFallback` | Opens target webpage. |
| **Window State** | `BlockBasicWithFallback` | Adjusts window display state and dimensions. |

## Window State Block Settings

### Main Parameters

| Parameter | Description | Options & Details |
| :--- | :--- | :--- |
| **Description** | Short block description | Frameless header |
| **Device** | Window display state | • `Minimized` (Minimize to Taskbar)<br/>• `Normal` (Default windowed state)<br/>• `Maximized` (Fullscreen window) |

### Settings Parameters

* **Timeout (millisecond)**: Maximum execution duration for this block.
* **Delay time (millisecond)**: Delay before changing window state.

---

### Use Cases

* **Minimize on Run**: Minimize newly launched browser windows to taskbar to prevent desktop distraction during automation runs.
* **Maximize for Rendering**: Maximize window size when capturing full desktop screenshots or rendering complex responsive layouts.
